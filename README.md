# Typedantic website

Public site for the [Typedantic](https://github.com/dfunani/typedantic) TypeScript validation library — docs, how-to guides, API reference, and examples (Django-style information architecture).

```bash
cd typedantic-web
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Path | Purpose |
|------|---------|
| `/` | Homepage — Meet Typedantic |
| `/docs` | Getting started + topics |
| `/docs/howto` | Task-oriented how-to guides |
| `/reference` | API (`@typedantic/*`) |
| `/examples` | Copy-paste models |
| `/download` | Install |
| `/community` | GitHub, npm, contribute |
| `/contribute` | Contributor workflow |

Published packages: `@typedantic/core`, `@typedantic/model`, `@typedantic/settings` (v1.0.0).
