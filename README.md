# Typedantic website

Public site for the [Typedantic](https://github.com/dfunani/typedantic) TypeScript validation library.

```bash
cd _typedantic-web
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Path | Purpose |
|------|---------|
| `/` | Homepage |
| `/docs` | Guides |
| `/reference` | API |
| `/examples` | Copy-paste models |
| `/download` | Install |
| `/contribute` | Repo workflow |
